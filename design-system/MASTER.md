# Sales Studio design system
Style: Minimalism & Swiss (ui-ux-pro-max). Layout: /setup centered conversation; /studio workspace (assistant left, canvas right; bottom sheet on mobile).
Color rule: white/black/grey everywhere. Red = urgent/negative, Green = positive/done. Always pair with icon or label. Charts default to ink/grey; only highlighted marks use red/green.
Type: system/Inter stack, no CDN; tabular numerals for numbers; body 16px, line-height 1.5.
Spacing 4/8/12/16/24/32/48; 1px borders, no shadows; 44px min touch targets; one primary black button per screen.
Motion: 150–250ms, respects prefers-reduced-motion. Icons: inline SVG (Lucide), no emoji.
Tokens: web/tokens.css (also read by the PNG report renderer).
